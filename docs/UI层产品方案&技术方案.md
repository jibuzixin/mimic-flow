## 二、产品方案

### 2.1 产品定位 & 设计理念

**Mimic Flow** - 基于 AI 的可视化工作流编排与执行平台

**设计理念**：
- ✨ **丝滑灵动**：核心页面（工作流编排）要有优秀的动效和交互反馈，整体 UI 保持高水准
- 🧩 **积木式编排**：低门槛，类似 Scratch 的块堆叠体验，支持拖拽、嵌套、动画
- 🌳 **可视化流程**：分支/循环用箭头和缩进直观展示，避免平铺不直观
- 🎨 **可定制**：工作流卡片支持自定义背景，打造个性化体验
- 🔔 **强感知**：任务状态变化通过弹窗+声音及时通知用户

### 2.2 整体信息架构

```
┌─────────────────────────────────────────────────┐
│  侧边栏导航（4个主页面）                          │
├──────────┬──────────────────────────────────────┤
│          │                                      │
│  📊 仪表盘 │  首页概览 + 快捷操作 + 统计数据       │
│          │                                      │
│  🔀 工作流 │  工作流库 → 编辑器（点击进入）        │
│          │                                      │
│  📝 日志  │  执行记录 + 日志详情（默认最近一次）   │
│          │                                      │

```

**导航精简为 4 个主页面**：仪表盘、工作流、日志、设置

- 悬停预览节点样式

##### 画布区（中间）- 核心交互

**视觉设计**：
- 深色/浅色主题，节点带玻璃拟态效果
- 节点之间用**贝塞尔曲线箭头**连接，箭头有**流动光效**（表示执行方向）
- 选中节点：边框发光 + 轻微放大 + 阴影加深
- 分支节点：True/False 分支用不同颜色的曲线箭头
- 循环节点：用回环箭头表示循环关系

**动效设计**：
- 节点拖入：弹性缩放出现（ease-out-back）
- 节点删除：缩小 + 淡出
- 连线：绘制动画（从起点流向终点）
- 执行时：节点依次高亮 + 连线光效流动
- 悬停节点：微妙上浮 + 阴影变化

**积木式 + 可视化箭头**：
- 主体是积木式纵向堆叠
- 遇到 if/loop 等控制节点，自动展开嵌套 + 绘制分支箭头
- 用户也可以切换"纯积木视图" / "流程图视图"
- 节点可拖拽排序，拖动时实时预览放置位置（插入线）

##### 属性面板（右侧）

**设计原则**：零代码、可视化配置、字段有说明

**通用属性**：
- 节点名称（可编辑）
- 节点 ID（只读，灰色小字）
- 超时时间（数字输入 + 单位）
- 重试次数（数字选择器）
- 失败时：[停止执行 ▾] / 继续执行

**各节点专属属性**（示例）：

| 节点 | 属性配置方式 |
|------|-------------|
| 变量赋值 | 变量名（下拉选择已有变量 + 新建）、操作类型（set/add/subtract等）、值（输入框 + 变量选择） |
| 条件判断 | 条件构建器：左边变量（下拉） + 运算符（下拉：==/!=/>/</>=/<=） + 右边值（输入 + 变量选择） |
| 循环 | 循环类型（for/while/forEach下拉）、各类型对应参数 |
| AI 操作 | 提示词（大输入框）、deepThink（开关）、deepLocate（开关）、cacheable（开关） |
| 点击元素 | 目标描述（输入框）、deepLocate（开关） |
| AI 查询 | 提示词（大输入框）、输出变量名（输入框） |

**每个字段旁有 "?" 帮助图标**，hover 显示详细说明。

### 2.5 通知 & 交互体验

#### 通知系统

| 场景 | 触发方式 | 可配置 |
|------|---------|-------|
| 任务成功完成 | 弹窗 + 声音 | ✅ 开关 |
| 任务执行失败 | 弹窗 + 声音（不同） | ✅ 开关 |
| 任务开始执行 | 可选最小化窗口 | ✅ 开关 |
| 配置缺失/错误 | 友好提示条 + 跳转按钮 | 不可关 |

弹窗样式：
- 右下角滑入，带渐变背景和图标
- 成功：绿色 + ✓ 图标
- 失败：红色 + ❌ 图标
- 点击弹窗直接跳转到对应日志详情

#### 帮助系统

- **字段 Tooltip**：所有晦涩字段旁有 "?" 图标
- **节点说明**：节点库每个节点有简介，拖拽时显示详细说明
- **空状态引导**：工作流库为空时，显示引导创建
- **错误提示**：用通俗语言解释错误，附"可能原因"和"解决办法"

### 3.1 技术栈

### 3.4 节点元数据注册

每个节点定义元数据（名称、图标、分类、属性Schema），用于节点库渲染和属性面板生成：

```typescript
interface NodeConfig {
  type: string;
  name: string;
  category: 'control' | 'ai-action' | 'ai-query' | 'wait';
  icon: ComponentType;
  description: string;
  defaultParams: Record<string, unknown>;
  propertySchema: PropertyField[];  // 用于自动生成属性面板
}
```
