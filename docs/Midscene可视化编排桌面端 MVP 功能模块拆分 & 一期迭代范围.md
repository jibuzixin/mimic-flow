# Midscene可视化编排桌面端 MVP 功能模块拆分 \& 一期迭代范围

## 一、MVP 核心定位（一期只做这件事）

**目标：最小可用完整闭环**

搭建「桌面端可视化编排工具」，实现：**画布拖拽编排 \+ 视频录屏自动生成流程 \+ 调度器中转执行 Midscene \+ 运行日志可视化**。

严格遵守架构分层：

- UI层：只编辑、只展示，不直接执行自动化

- 调度层：统一解析流程、补全循环/分支/重试、转译 Midscene 指令

- 引擎层：Midscene 仅负责原子UI操作，无上层流程逻辑

- 多模态层：视频解析归一化输出标准Flow JSON

**一期绝对不做：**语音解析、云端协作、定时任务、插件市场、多设备并发、团队权限、YAML手动编辑高级功能。

## 二、整体产品五大模块拆分（全量架构）

为方便迭代分层，整体拆分为 5 大核心模块，一期只落地「核心刚需模块」：

1. **桌面客户端底座模块**（Electron 跨平台基础）

2. **可视化画布编排模块**（ReactFlow 核心编辑器）

3. **多模态输入解析模块**（一期仅落地：视频解析生成流程）

4. **流程调度运行时模块**（架构核心，解耦 Midscene）

5. **模型配置 \& 日志报告模块**（双模型隔离、日志汇聚）

## 三、一期迭代（MVP）详细功能清单【可直接排期开发】

### 模块1：Electron 桌面端底座（一期全落地）

目标：搭建稳定跨平台桌面壳，统一本地存储、进程通信、全局配置

- Windows/Mac/Linux 基础打包运行

- 本地文件持久化：流程文件、录屏文件、报告缓存

- 全局设置面板（一期核心）：
        

    - Midscene视觉模型配置（Key/BaseUrl/模型名/超时/缓存开关）

    - 多模态流程解析模型配置（视频解析专用）

    - 全局运行策略：默认重试次数、页面超时、失败策略

- Electron主进程/渲染进程IPC通信封装（画布→调度器统一通道）

- 应用缓存自动清理、日志生命周期管理

### 模块2：可视化画布编排模块（一期最小完整可用）

目标：实现**类Dify零代码编排**，可从零搭建可执行自动化流程

#### 1\. 画布基础能力

- 画布缩放、平移、框选、撤销/重做、复制粘贴节点

- 节点拖拽、锚点连线、拓扑渲染

- 流程预校验：非法连线、空参数、变量引用错误检测

#### 2\. 一期支持的核心节点（完全适配Midscene能力）

- 原子操作节点：页面打开、点击、输入、等待、滚动

- AI节点：aiTap、aiInput、aiQuery、aiAssert

- 流程控制节点：if条件分支、循环节点（for循环）

- 通用节点：重试配置、超时配置、失败策略配置

#### 3\. 节点属性面板

- 单节点超时、重试次数、失败策略

- AI节点自定义业务描述、局部ActionContext

- 变量绑定、变量插值可视化配置

#### 4\. 流程文件能力

- 新建/保存/另存为/打开本地流程文件（标准Flow JSON）

- 画布数据 ↔ 标准Flow JSON **双向无损转换**

### 模块3：多模态输入解析模块（一期仅落地视频解析）

目标：实现「上传操作录屏 → 自动生成画布流程」核心亮点功能

- 本地MP4视频上传、大小/时长校验（限制10分钟内）

- 服务端视频切片：每3s截取一帧、生成时序帧序列

- 调用**多模态流程解析模型** \+ 内置固定提示词

- 模型返回动作数组 → 自动转换标准Flow JSON

- 前端自动渲染完整画布节点、高亮模糊/未知节点

- 支持用户手动修正节点、补充分支循环、完善流程

**一期砍掉：语音ASR解析、PPT/图片导入、批量解析**

### 模块4：流程调度运行时（一期核心架构全覆盖）

这是一期**最重要、最核心**模块，实现Midscene能力补强与解耦

- 解析平台标准Flow JSON，完整识别：变量池、拓扑节点、分支、循环、重试、超时

- **Flow JSON → 分段Midscene YAML转换引擎**（核心）

- 流程执行调度：顺序执行、分支判断、循环迭代、异常捕获、失败重试

- 统一初始化Midscene Agent，注入全局模型配置、ActionContext

- 执行状态实时回调：运行中/成功/失败、实时截图、推理日志

- 变量池实时更新：节点输出变量全局透传

- 阻断前端直接调用Midscene，**所有执行统一走调度器**

### 模块5：模型管理 \& 日志报告模块（一期基础闭环）

#### 1\. 双模型隔离配置（严格对齐架构）

- Midscene视觉模型：运行时页面操作专用

- 多模态解析模型：视频生成流程专用

- 全局一次配置、全流程复用，支持单流程独立覆盖模型

#### 2\. 日志汇聚与可视化

- 汇聚两层日志：调度器流程日志 \+ Midscene内核日志

- 前端实时展示：节点执行记录、AI推理内容、报错信息、截图预览

- 运行完成自动生成HTML报告，本地保存、支持打开查看

## 五、一期 MVP 最终闭环能力（产品可演示、可交付）

用户完整操作链路（一期全部跑通）：

1. 管理员后台一次性配置双模型Key与全局运行参数

2. 方式一：用户拖拽画布，从零搭建带分支/循环/AI操作的自动化流程

3. 方式二：用户上传操作录屏视频，AI自动生成完整画布流程

4. 用户手动微调流程、补充逻辑、修正识别误差

5. 点击运行，调度器统一调度、分片转译Midscene指令执行

6. 实时查看节点状态、AI日志、页面截图

7. 运行结束生成完整报告，保存流程文件可复用
